# Free Minecraft Java server hosting from a phone browser

This option uses a separate hosting provider for the live server while GitHub holds the project files. It is **not GitHub-only**.

1. Open a provider's website in your phone browser and create an account.
2. Create a **vanilla Java Edition 1.21.11** server if that exact version is offered.
3. Check the host's current free-plan limits, sleep/idle policy, memory cap, world backups, and public TCP port support before choosing it.
4. Keep Java authentication enabled and use a whitelist.
5. Share the address only after the server is running and you have successfully joined from a Java client.

Free hosts can suspend or sleep servers and may change their limits. A free plan is not a promise of unlimited 24/7 uptime. Do not enter payment details or enable paid upgrades if you want to remain on a $0 plan.

GitHub Actions can prepare the official vanilla Minecraft Java 1.21.11 server bundle, but the bundle is not a live server. See [runtime bundle instructions](get-runtime-bundle-from-github.md).
